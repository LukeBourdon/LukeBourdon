# Security policy suite

Four board-submission policy drafts for fictional Northbridge Cloud Services Ltd, prepared as a GRC portfolio project by Luke Bourdon.

Read the [company context](company-context.md), then the [board paper](board-paper.md).

| Document | Purpose |
| --- | --- |
| [Acceptable use](acceptable-use-policy.md) | Practical workforce rules for devices, services, information and reporting |
| [Incident response](incident-response-policy.md) | Authority, severity, response, evidence and notification decisions |
| [Access control](access-control-policy.md) | Joiners, movers, leavers, privileged access and reviews |
| [Data classification](data-classification-policy.md) | Four classification levels with a handling matrix |
| [Governance records](governance-records.md) | Exception, acknowledgement, incident and approval record templates |

**Status:** v1.0, submitted for fictional board consideration on 14 September 2026. Approval and effective dates are intentionally pending. These are proposed controls, not proof of baseline implementation.

Skills demonstrated: policy drafting, accountability, proportionate requirements, exception governance, measurable assurance and executive decision support.
