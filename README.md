# ISO/IEC 27001:2022 Annex A gap analysis

A complete, fictional desk assessment of Northbridge Cloud Services Ltd, prepared by Luke Bourdon on 14 September 2026.

**93 of 93 control references assessed:** 37 organisational, 8 people, 14 physical and 34 technological. 5 Implemented, 61 Partial, 27 Missing. All 93 are applicable in this deliberately broad scenario; no exclusion is inferred merely because cloud providers operate infrastructure.
